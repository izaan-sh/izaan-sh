| 🛡️ | **[Wazuh Home SOC Lab](https://github.com/izaan-sh/Wazuh-Home-SOC-Lab)** | Wazuh + Sysmon across Windows and Linux. Custom detection rules, FIM, and Active Response that auto-blocks SSH brute force, tested from detection through recovery. |

Investigated the attack using Sysmon, Windows logs, Sentinel, and KQL. |
| 🧪 | **[CVE-2024-38063 Lab](https://github.com/izaan-sh/CVE-2024-38063-Exploitation-Detection-Mitigation-Lab)** | Simulated the exploit from Kali, detected it with Suricata, correlated alerts with Sysmon, and tested mitigations. |

<summary><b>More on the Cloud SOC Lab</b></summary>

- KQL to investigate failed network logons and suspicious source IPs
- Analytics rules for repeated failed authentication
- Troubleshot RBAC permissions, Logic App entity payloads, expressions, and NSG rule priorities
- Workbook visualising auth failures, incidents, source IPs, targeted accounts, and GeoIP activity

</details>

<details>
<summary><b>More on the Wazuh Home SOC Lab</b></summary>

- Deployed Wazuh SIEM and endpoint monitoring, with Sysmon telemetry from Windows
- File Integrity Monitoring and custom detection rules
- Monitored authentication and user-account activity
- Simulated repeated failed SSH logins and blocked the source IP with Active Response

</details>

<details> 
<summary><b>More on the Windows Threat Hunting & IR Lab</b></summary>

- Built a Windows endpoint telemetry environment using Sysmon, Windows Security logs, PowerShell logging, and Microsoft Sentinel
- Simulated a controlled multi-stage attack chain from initial access through persistence and post-exploitation activity
- Used KQL to hunt for authentication abuse, PowerShell execution, account creation, privilege escalation, scheduled tasks, file staging, and network activity
- Investigated events across multiple telemetry sources and correlated activity into a single attack timeline
- Documented detection logic, investigation steps, attack evidence, and response considerations

</details>
